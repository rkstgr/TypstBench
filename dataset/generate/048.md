Set the document font to "IBM Plex Sans". Create a revision note showing: "Original price: $50" with $50 struck through, (on the next line) followed by "New price: $35" where $35 is highlighted in green.
---
```typst
#set text(font: "IBM Plex Sans")

Original price: #strike[\$50] \
New price: #highlight(fill: green)[\$35]
```
