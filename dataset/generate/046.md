Create a warning message that says "WARNING:" in bold, red, 16pt text, followed by "This document contains " in regular text, then "confidential information" in italic blue text. All text after WARNING should be 12pt.
---
```typst
#text(size: 16pt, fill: red, weight: "bold")[WARNING:] #text(size: 12pt)[This document contains #emph(text(fill: blue)[confidential information])]
```
