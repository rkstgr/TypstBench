Explain why these two show rules produce different visual results:

Version A:
```typst
#show strong: it => text(fill: blue, upper(it.body))
The *key terms* are important.
```

Version B:
```typst
#show strong: it => text(fill: blue, upper(it))
The *key terms* are important.
```

---

Version A produces blue uppercase text that is NOT bold, while Version B produces blue uppercase text that IS bold.

**Explanation:**
- `it.body` extracts only the text content ("key terms") without the bold formatting
- `it` refers to the entire strong element, preserving its bold nature when transformed
- When `upper()` processes `it`, it maintains the element's inherent bold formatting
- When `upper()` processes `it.body`, it only gets plain text without formatting
